## F. 盘点要求

审查Agent 在盘点时必须覆盖：
- 主链路页面
- 状态页
- 结果页
- 异常页
- 售后页
- 消息触达页
- 审核/处理中页面
- 用户补救动作页面

如果只是列出首页、详情页、个人中心这类主页面，则盘点视为不合格。
