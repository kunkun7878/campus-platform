# 团队智能体注册表

> 这是校园聚合平台多智能体团队的固定注册表。

## 总原则
- 默认采用：**总控主智能体 + 子智能体按需派生 + 质量审查打回闭环**
- 所有任务优先按团队协作执行，不再默认单智能体独跑
- 总控主智能体负责：读状态、拆任务、派工、收口、同步记忆

## 固定角色
### 1. 总控主智能体
- 绑定会话：当前主会话（main）
- 角色文档：[[02-主智能体工作说明]]
- 运行手册：[[总控主智能体运行SOP]]
- 默认模型：`gpt-5.4`
- 职责：总控编排、任务树、分工、仲裁、最终汇报

### 2. 结构规范智能体
- 角色文档：[[03-结构规范智能体工作说明]]
- 默认模型：`gpt-5.4`
- 职责：页面总表、状态矩阵、命名规范、组件清单、结构边界

### 3. 主链路执行智能体
- 角色文档：[[04-执行智能体工作说明]]
- 默认模型：`deepseek/deepseek-v4-flash`
- 职责：主链路页面执行

### 4. 补充链路执行智能体
- 角色文档：[[04-执行智能体工作说明]]
- 默认模型：`deepseek/deepseek-v4-flash`
- 职责：异常态 / 补充页 / 次链路页面执行

### 5. 质量审查智能体
- 角色文档：[[05-质量审查智能体工作说明]]
- 默认模型：`gpt-5.4`
- 职责：独立审查、打回、复审、合并前把关

## 团队运行规则
1. 新任务先由总控主智能体判断是否需要拆分
2. 涉及结构问题，先派结构规范智能体
3. 涉及具体页面执行，可并行派主链路执行智能体 / 补充链路执行智能体
4. 所有执行结果必须经质量审查智能体
5. 审查不通过，必须打回原执行智能体修复
6. 总控主智能体统一收口并触发 `campus-memory-sync`

## 启动顺序
1. 总控主智能体读取 `[[PROJECT_HOME]]`、`[[campus_status]]`、`[[iteration_current]]`
2. 总控主智能体用 `brainstorming` / `writing-plans`
3. 总控主智能体按需派生其他智能体
4. 质量审查智能体验收
5. 总控主智能体回填记忆系统
