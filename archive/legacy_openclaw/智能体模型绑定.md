# 智能体模型绑定

> 目标：明确当前校园聚合平台多智能体工作流中，各角色默认绑定哪些 AI 模型，以及何时升级模型。

## 默认绑定
- **总控主智能体**：`gpt-5.4`
- **结构规范智能体**：`gpt-5.4`
- **主链路执行智能体 / 补充链路执行智能体**：`deepseek/deepseek-v4-flash`
- **质量审查智能体**：`gpt-5.4`

## 升级到 Claude 的条件
当你已经配置 Claude 后，以下场景推荐升级：
- 最终终审
- 多智能体结果冲突仲裁
- 高价值版本的风险复核
- 复杂结构重构前的评审

## 不同模型的角色适配
### gpt-5.4
适合：
- 总控编排
- 长上下文理解
- 结构归纳
- 审查收口

### deepseek-v4-flash
适合：
- 页面执行
- 快速试错
- 高频迭代
- 成本敏感的大批量具体任务

### Claude（可选高配）
适合：
- 高价值终审
- 反复打回仍不收敛的复杂问题
- 风险判断与最终拍板辅助

## 当前建议
- 日常跑：总控主智能体 / 结构规范智能体 / 质量审查智能体 用 `gpt-5.4`
- 高频执行：执行智能体（主链路 / 补充链路）用 `deepseek-v4-flash`
- 关键终审：必要时临时升级 Claude
